# Licensing and redistribution

Apache-2.0 is the owner's standing choice for owner-controlled GAMS/example code.
It does not replace any third-party license. Full upstream terms accompany this
repository in game/THIRD_PARTY_LICENSES/ and THIRD-PARTY-NOTICES.txt, and accompany
both distributed ZIPs. NOTICE identifies source pins and bounded linkage findings.

The collected source/build review found no identifiable third-party permission
blocker. Earlier local demo infrastructure has recorded lineage but unconfirmed
earliest authorship; this limitation remains disclosed. Conservative notices for
runtime/math/compiler helper sources are retained without claiming every helper
survives linking. Build tools are not shipped as visitor-game executables.

THIRD-PARTY-REVIEW.md and THIRD-PARTY-AUDIT.json preserve the source-level findings;
raw comparison evidence remains under packaging/ecosystem/example_game1/audit/
in the preparation repository. They are not certification of any earlier binary.
The new release must build from pinned sources, retain build receipts, verify its
bundled public Unit pins, and pass candidate inspection. NOTICE binds the prepared
source/license inventory through NOTICE-EVIDENCE.json. Exact Actions digest gates
remain separate from the standing first-party license choice.

Host and Unit packages retain their own licensing/notices. The Project ZIP keeps
these under notices/project-units/. The browser game does not require those Units
or a running GAMS Host.
