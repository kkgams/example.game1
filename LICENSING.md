# Licensing and publication gate

`LICENSE` applies to GAMS-authored source. `NOTICE` identifies third-party
and inherited game infrastructure; `game/THIRD_PARTY.md` records exact pinned
Sokol downloads, checksums, modified files and upstream terms. The template
ships neither downloaded Sokol source/binaries nor built game outputs.

**Owner review required before any public push or release:** establish provenance
of the earlier demo infrastructure, audit all source/fixture/license bytes and
third-party license text, verify Sokol build receipts and modifications, and
review linked game output and bundled notices separately if distributing the
visitor game. Extraction and local smoke tests are not approval.
